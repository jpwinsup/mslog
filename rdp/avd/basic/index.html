基本情報の取得

  • 前提

    トリアージを行うことを目的としています。
    ご利用の Azure Virtual Desktop や接続元端末の環境情報について包括的に情報採取を行います。
    本情報採取実施以降、調査方針によっては、別途追加採取を依頼する可能性がございます。
    また、一部のログは、保存期間が 2 日間しかないログもあることから早期にログ採取を実施ください。

  • 情報採取スクリプトファイルの取得について

    情報採取用ツールについては、後述の Windows PowerShell や手順内にリンクを記載しておりますが、取得リンクや、注意について記載をさせていただきます。 今回ご案内差し上げる手順では、Windows PowerShell のコマンド内に、情報採取ツール取得に必要な手順を含めております。もし、情報採取実施環境がインターネット アクセスが出来ない場合は、以下の URL より “TSS.zip” をダウンロードおよび展開いただき、対象端末へ配置します。

    ダウンロード先: https://aka.ms/getTSS
    ※ 2024年7月8日以降ツールの入手方法の変更が計画されています。該当 URL にアクセスできない場合、サポート リクエストを発行の上、担当エンジニアまでご連絡ください。
    ※ 採取対象環境がインターネット アクセス可能環境且つ、後述の Windows PowerShell コマンドでの入手可能な場合は、上記リンクから別途入手をいただく必要はございません。

    注意
    TSS (Trouble Shooting Script) は、機能の拡張などにより内容が変更されることがあります。
    そのため毎回上記のダウンロード先から “TSS.zip” をダウンロードいただき使用してください。
    また、上記のダウンロード先にアクセスできない場合は、以下のサイトに記載されているダウンロード先からダウンロードして使用してください。
    https://learn.microsoft.com/en-us/troubleshoot/windows-client/windows-troubleshooters/introduction-to-troubleshootingscript-toolset-tss

  • 資料採取手順

    注意 資料採取中、接続元と接続先は再起動しないでください。

  1. “TSS.zip” の準備をします。(例では C:\TSS)
    ※ 接続元と接続先の両方で実施
    1.1 “TSS.zip” の最新版をダウンロード～展開をコマンドで実行する場合の手順
    1.1.1 管理者として PowerShell を実行し、以下のコマンドより、“TSS.zip” の最新版をダウンロードし、展開します。

    md C:\TSS
Set-ExecutionPolicy -scope Process -ExecutionPolicy RemoteSigned -Force
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Start-BitsTransfer https://aka.ms/getTSS -Destination C:\TSS\TSS.zip
Expand-Archive -LiteralPath C:\TSS\TSS.zip -DestinationPath C:\TSS -force
cd C:\TSS

    1.2 “TSS.zip” の最新版を事前にダウンロードした場合の手順
    1.2.1 管理者として PowerShell を実行し、以下のコマンドより、スクリプトの実行を許可します。

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

    1.2.2. “TSS.zip” の展開後、展開したパスに移動します。

     cd "C:\TSS"

  2. 以下のコマンドにより、ログを収集します。

    .\TSS.ps1 -CollectLog UEX_AVDCore, UEX_AVDProfiles, UEX_AVDDiag -BasicLog

    ※ 接続元と接続先の両方で実施

  3. 使用許諾の確認 (End User License Agreement) のメッセージが表示された場合は、ご一読いただき同意いただける場合は [Accept] をクリックし、画面キャプチャーの取得に関する警告メッセージが表示されたら、[Y] を入力します。
    ※ 接続元と接続先の両方で実施

  4. C:\MS_DATA に TSS_<コンピューター名><日付>-<時間>.zip が生成されるため、弊社のエンジニアから案内されたサイトにアップロードください。
    ※ 接続元と接続先の両方で実施
