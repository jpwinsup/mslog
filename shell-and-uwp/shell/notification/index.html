通知が表示されない事象の調査

目次

  • 情報採取スクリプトファイルの取得について
  • 資料採取手順

本記事はマイクロソフト社員によって公開されております。

こんにちは。 Windows Performance チームの栗木です。 ポップアップ通知が表示されない事象を弊社にお問い合わせいただく際に、事前に採取しておいたほうが良い資料についてご紹介させていただきます。

情報採取スクリプトファイルの取得について

以下の URL より “TSS.zip” をダウンロードおよび展開いただき、対象端末へ配置します。

ダウンロード先: https://aka.ms/getTSS

※ TSS は機能の拡張などにより内容が変更されることがあります。そのため、毎回上記のダウンロード先から TSS を取得いただき使用してください。

資料採取手順

  1. 設定アプリ（Windows キー + I）から システム → 通知 で意図通りの通知設定になっていることを確認し、スクリーンショットを取得します。

  2. 管理者としてPowerShell を実行し、以下のコマンドより、スクリプトの実行を許可します。

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

  3. TSSを展開したパスに移動します。

    cd "C:\path\to\TSS"

  4. 以下のコマンドより、資料採取を実行します。

    .\TSS.ps1 -Start -UEX_WPN -UEX_WSC -WPR General -Procmon -PSR -Basiclog -LogFolderPath "C:\MS_DATA"

    画面の指示にそって進み、以下のメッセージが出力されるまで待ちます。
    Reproduce the issue and enter ‘Y’ key AFTER finishing the repro (with window focus here) [Y]?

  5. お客様環境で通常であれば通知が表示される操作を実施して、通知がされる、または通知されないことを確認します。

  6. すべての通知が表示されないのか、それとも個別の通知が表示されないのかを切り分けのためにテスト通知を実施します。
    コマンド プロンプトを別に起動させ、以下のコマンドでテスト用の通知を発行し、通知がされる、または通知されないことを確認します。

    wlrmdr.exe -s 60000 -f 1 -t test -m test -a 0

  7. 管理者として起動していた PowerShell に戻り、 ‘Y’ を入力し、資料採取を終了します。

  8. C:\MS_DATA フォルダーに資料 (Zip ファイル) が出力されておりますので、弊社へご提供ください。

  9. 手順１で取得したスクリーンショットと通知の関連データが保存されている以下のフォルダーをコピーし、こちらも弊社へご提供ください。

    C:\Users\<ユーザー名>\AppData\Local\Microsoft\Windows\Notifications

以上となります。本ブログが少しでも皆様のお役に立てば幸いです。

本情報の内容（添付文書、リンク先などを含む）は、作成日時点でのものであり、予告なく変更される場合があります。
